# Welcome to your Expo app 👋

This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in a

- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go), a limited sandbox for trying out app development with Expo

You can start developing by editing the files inside the **app** directory. This project uses [file-based routing](https://docs.expo.dev/router/introduction).

## Get a fresh project

When you're ready, run:

```bash
npm run reset-project
```

This command will move the starter code to the **app-example** directory and create a blank **app** directory where you can start developing.

# 🎨 UI Design System

This project follows a **minimal, clean, and mobile-first design approach** focused on simplicity, readability, and a premium user experience.

---

## 📱 Design Philosophy

- Keep the UI simple and clutter-free  
- Focus on usability over decoration  
- Maintain consistent spacing and hierarchy  
- Use soft colors and smooth elements  
- Ensure high readability across all screens  

---

## 🎯 Color Palette

### 🔵 Primary Color
- `#4F8EF7` — Used for primary actions, buttons, and highlights  

### 🔷 Secondary Color
- `#DCEBFF` — Used for cards, backgrounds, and selected states  

### ⚪ Background Colors
- `#F8FAFC` — Main app background  
- `#FFFFFF` — Cards and surfaces  

### ⚫ Text Colors
- `#1E293B` — Primary text  
- `#64748B` — Secondary text  

### 🟠 Accent Color
- `#F59E0B` — Used for important actions, highlights, and CTAs  

### 🟢 Success Color
- `#22C55E` — Used for completed states and success indicators  

---

## 🔤 Typography

### Primary Font
- Inter — Used across the entire application for a clean and modern look  

### Alternative Font (Optional)
- Poppins — For a slightly more friendly and rounded appearance  

---

## 🔠 Font Scale

| Type        | Size        |
|-------------|------------|
| Heading     | 20–24px     |
| Subheading  | 16–18px     |
| Body Text   | 14–16px     |
| Small Text  | 12–13px     |

---

## 🧩 UI Components Guidelines

### Buttons
- Rounded corners  
- Primary buttons use Primary Color  
- Clear visibility and strong contrast  

### Cards
- Light background (`#FFFFFF` or `#DCEBFF`)  
- Soft shadows  
- Proper padding and spacing  

### Icons
- Minimal and consistent style  
- Use line or soft-filled icons  

---

## 📐 Layout & Spacing

- Follow a consistent grid system  
- Maintain padding using 8px / 16px / 24px scale  
- Avoid overcrowding elements  
- Ensure mobile-first responsiveness  

---

## ⚠️ Design Rules

- Avoid using too many colors  
- Do not mix multiple font families unnecessarily  
- Keep contrast high for readability  
- Focus on clarity over visual complexity  

---

## 🚀 Summary

This design system ensures that the app remains:

- Simple  
- Clean  
- Consistent  
- User-friendly  

while delivering a modern and premium mobile experience.
